Share live terminal output with your team.

Pipe a deployment, build, or log file to a browser link. Teammates can follow along as it happens, without SSH access or a shpellcast account.

Share a run in three steps

  1. Pipe your commandPoint curl or nc at your shpellcast server.
  2. Share the linkCopy the URL as soon as it appears and send it to your team.
  3. Watch togetherOpen the link in a browser. The output updates as the command runs.

Commands you can copy

Replace cast.example.com with your server’s hostname. 2>&1 includes errors in the stream.

Share a deployment

Let your team follow a rollout and see the health checks as they finish.

./deploy.sh 2>&1 | curl -fsSN -T - https://cast.example.com/ingest

Follow a live log file

Share incoming application logs while you troubleshoot together. Press Ctrl+C to stop following.

tail -f app.log | curl -fsSN -T - https://cast.example.com/ingest

Stream build output on a trusted network

Send compiler and build messages with OpenBSD nc. This connection uses plain TCP.

make build 2>&1 | nc -N cast.example.com 9696

Self-host on Ubuntu or Debian

Run the installer on your server. It guides you through choosing an address, HTTPS, and how long links stay available. shpellcast runs as one binary.

curl -fsSL https://raw.githubusercontent.com/shpellcast/shpellcast/v1/install.sh | sudo bash

Unattended install and configuration

Before you share

Who can see my output?

Anyone with the link can watch. Share it only with the people who need it, and keep secrets and credentials out of the output.

How long does a link last?

The default lifetime is 24 hours after output stops. Your server administrator can change it.

Can I save a copy of the logs?

Use Download raw in the viewer. With disk saving enabled, it includes the full log. In memory-only mode it includes the recent output the server has kept.
